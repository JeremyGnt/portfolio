# Portfolio

Portfolio personnel de **Jeremy**, développé pour présenter mes projets, mes compétences techniques et mon parcours.

> 🧑‍💻 **Projet personnel** conçu, développé et maintenu de manière indépendante.

---

## 🚀 À propos du projet

Ce portfolio a été conçu comme une vitrine professionnelle pour :

- présenter mes projets académiques et personnels,
- valoriser mes compétences, mes expériences,
- proposer une expérience utilisateur claire, fluide et responsive,
- centraliser mes informations de contact et mon profil.

---

## 🧠 Compétences démontrées

- Développement front-end moderne avec **Vue**
- Structuration d’application en **TypeScript**
- Intégration UI propre et responsive (CSS/HTML)
- Gestion de composants réutilisables
- Organisation de projet front maintenable
- Déploiement d’un site vitrine technique

---

## 🛠️ Stack technique

- **Vue** (~57.3%)
- **TypeScript** (~26.7%)
- **CSS** (~9.6%)
- **JavaScript** (~3.9%)
- **HTML** (~2.5%)

## 📁 Structure (typique)

```text
portfolio/
├─ src/
│  ├─ components/       # Composants UI
│  ├─ views/            # Pages principales
│  ├─ assets/           # Ressources statiques
│  ├─ router/           # Routage de l’application
│  └─ main.ts           # Point d’entrée
├─ public/              # Fichiers publics
├─ package.json
└─ README.md
```

> L’organisation peut évoluer selon les versions.

---

## ⚙️ Prérequis

- **Node.js** (version LTS recommandée)
- **npm** (ou yarn/pnpm)

Vérification :

```bash
node -v
npm -v
```

---

## 🚀 Installation & lancement

### 1) Cloner le dépôt

```bash
git clone https://github.com/JeremyGnt/portfolio.git
cd portfolio
```

### 2) Installer les dépendances

```bash
npm install
```

### 3) Lancer en développement

```bash
npm run dev
```

---

## 🏗️ Build de production

```bash
npm run build
```

Prévisualisation locale du build (si script disponible) :

```bash
npm run preview
```
